# Regional Food Prices

Place verified price survey datasets here.

## Required Fields

| Field | Description |
|-------|-------------|
| `canonicalFoodId` | Links to food canonical ID |
| `regionCode` | Links to region code |
| `price` | Price amount |
| `unit` | Price unit (per kg, per piece, etc.) |
| `currency` | ETB, USD, etc. |
| `observedAt` | Date price was observed |

## Required Provenance

- Survey name and methodology
- Source URL/reference
- Observation date

Do NOT invent prices.
